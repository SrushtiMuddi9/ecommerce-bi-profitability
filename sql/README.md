
# E-Commerce Business Intelligence & Profitability Analysis

## Project Overview
This project analyzes Brazilian e-commerce data to understand sales performance, customer behavior, product category performance, payment methods, and customer reviews.

The goal is to transform raw e-commerce data into meaningful business insights using Python, SQL, and Power BI.

## Tools & Technologies
- Python – Data cleaning and preprocessing
- Pandas & NumPy – Data manipulation
- SQL – Data analysis and querying
- Power BI – Interactive dashboards and visualization
- Excel – Data inspection and analysis

## Dataset
The project uses the Brazilian Olist e-commerce dataset.

Key data includes:
- Customer orders
- Order items and product prices
- Freight values
- Payment information
- Customer reviews
- Product categories

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing using Python
3. Data storage and analysis using SQL
4. KPI calculation and business analysis
5. Interactive dashboard development using Power BI
6. Business insights and recommendations

## Key Business Metrics
- Total item revenue
- Unique orders
- Average order value
- Monthly revenue trends
- Revenue by product category
- Payment method distribution
- Customer review analysis
- Freight value analysis

## Key Findings
- Total item revenue is approximately R$13.59 million.
- The dataset contains approximately 98,666 unique orders.
- Credit cards contribute the largest share of payment value.
- The average customer review score is approximately 4.09 out of 5.
- Product categories show different revenue and order-volume patterns.

## Dashboard Features
- KPI cards
- Monthly revenue trend
- Revenue by product category
- Payment method distribution
- Customer review score analysis
- Order volume by product category
- Revenue versus freight comparison
- Interactive date and category filters
- Business insights and recommendations

## Important Note
Actual profit cannot be calculated from the available dataset because complete product costs and operating expenses are not available. This project focuses on revenue and business performance analysis rather than claiming actual net profit.

## Future Improvements
- Include product and operational costs.
- Calculate actual profit margins when cost data becomes available.
- Add customer segmentation.
- Develop advanced sales forecasting.
- Improve dashboard interactivity.
